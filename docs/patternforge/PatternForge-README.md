# Pattern Forge Skill Bundle v2

Pattern Forge is packaged as one always-on-by-design orchestrator plus cooperating specialist modules.

## Main files
- `SKILL.md` — universal Pattern Forge instructions and ontology.
- `orchestration.yaml` — shared-state and module-coordination contract.
- `ontology-schema.json` — machine-readable pattern-node schema.
- `modules/` — specialist skills that work together through the orchestrator.

## Modules
- Router & orchestrator
- Cognition / logic / reasoning / decisions
- Language / narrative / speech / debate
- Vision / interface / design / morphology / biomimicry
- Code / algorithms / data / debugging
- Idea-to-System Forge for software + hardware
- Technology / systems / security / operations
- Physical / biological / environmental / complexity
- Social / strategic / organizational / economic
- Evidence / synthesis / creativity / verification

## Collaboration model
Modules share one task model rather than answering independently. They can run in parallel, hand work off sequentially, criticize/repair one another, and reconcile results before final verification.

## Activation note
The bundle is authored with `activation: always`. Actual account-wide or project-wide invocation depends on the host product's skill/project controls. The package itself cannot force global activation outside a host that supports it.
